# Stamp Duty Calculator UK

Free UK stamp duty calculator — enter property price, region and buyer type to
get instant SDLT (England/NI), LBTT (Scotland) or LTT (Wales) figures,
including first-time-buyer relief and second-home/buy-to-let surcharges.

**Live site:** [checkstampduty.co.uk](https://checkstampduty.co.uk)

## Features

- Universal calculator (England/NI, Scotland, Wales) — homepage
- Satellites: second home, Scotland (LBTT), Wales (LTT), first-time buyer,
  buy-to-let, thresholds
- **Refund calculator** (`/refund-calculator/`) — recomputes correct stamp
  duty and flags overpayment (second-home surcharge, missed Multiple
  Dwellings Relief, incorrect non-resident surcharge)
- Every satellite page carries a CTA into the refund calculator
- JSON-LD: WebApplication + FAQPage + HowTo + BreadcrumbList (kept for markup
  correctness / AI-crawler citability — HowTo/FAQ rich results are being
  retired by Google, not relied on for SERP display)
- `sitemap.xml` auto-generated by `generate-pages.js`

## Build

```bash
node generate-pages.js   # emits all satellite folders + refund-calculator/ + sitemap.xml
```

The homepage `index.html` is hand-written; everything else is generated.
`BANDS` in `generate-pages.js` must be kept in sync with the `<script>` block
in `index.html` if rates change.

## Deploy

Push to `main` → GitHub Pages workflow (`.github/workflows/pages.yml`)
publishes the repo root. Custom domain via `CNAME` (`checkstampduty.co.uk`) —
point DNS (CNAME record to `<username>.github.io`, or A records to GitHub
Pages IPs) before traffic will resolve.

## Data sources & disclaimer

Rates are **guidance** compiled from HMRC (SDLT), Revenue Scotland (LBTT) and
the Welsh Revenue Authority (LTT) published 2026 bands, applied
deterministically — **not** tax or legal advice. Always confirm with a
solicitor/conveyancer or the official HMRC SDLT calculator before exchange.
